# 变更记录

## 0.1.6 修订 11 - 2026-10-18

- 修复四条上游同时准备出口时的路由锁竞争；锁和拥有者同时发布，等待中的上游持续重试，不会以未知路由继续认证。
- 自动同步保留路由端自己的工作流，将上游工作流差异记入审查清单，使用现有权限发布待审查分支。
- 修订 10 的安装包在验证阶段被阻止发布，本修订重新构建。

## 0.1.6 修订 10 - 2026-10-18

- 控制台新增按端口注销和切换账号；注销暂停该上游自动认证，手动登录恢复。
- 合并状态、端口与账号读取，刷新不再因控件聚焦停止；限定请求等待时间，出错后恢复，离开页面时清理刷新任务。
- 同族备用目标与双栈并行探测，首个可靠响应结束等待；手动登录减少重复网关探测，提交成功后立即显示受理状态。
- 计费新增账户服务、套餐预约与取消、消费保护、MAC/无感认证及账号安全；App 和 LuCI 共用业务控件，不包含路由充值。
- 计费操作再次核对实际账号和可用选项，歧义结果不重放；中断的查询会结束等待并提示重试。
- 设置页移除旧单上游字段；日志可选系统或自定义目录，支持大小轮换和网页软链接；增加信息、调试、详细级记录。
- 增加稳定设备标识；App 记住密码时绑定网络特征，异网不自动发送凭据，旧资料需重新配对。
- 补齐展开、收起、进度和列表高度动画，稳定下拉菜单方向；滚动条对称预留，移动端缩窄且日志除外。
- 增加共享界面生成、LuCI 本地模拟验收及回归测试。此修订未在此前路由器局域网进行实机验证。

## 0.1.6 修订 8 - 2026-10-13

- 删除控制台中被主题覆盖的标题区域，账号编号完整显示；账号添加、编辑、排序和删除统一放在账号管理。
- 根据实机页面适配流量数值与标签的两种排列；计费页改为概览、用量与账单、在线设备；自动查询当前认证账号并按实际账号汇总余额、总流量和剩余流量，不含充值。
- 新增七类计费记录、跨 60 天日期分段、全局分页和本页 CSV 导出。
- App 内可编辑路由账号、上游和服务设置，并查询路由账单；无需跳转 Web 后台。
- 认证方式统一显示 bjut-sushe、bjut_wifi、lgn，兼容旧配置标识。
- 账号编号完整显示，同时保留进程参数检查，日志内容通过标准输入传递。

## 0.1.6 - 2026-10-11

- 修订 5 兼容关闭字符分类功能的 BusyBox，修复在线设备列表、空会话判断、SSID 与 lgn 页面校验；不会把 JSON 方括号或字段字母误删。
- 修订 4 修正 Argon 主题对页面标题的样式影响，并使用统一的网口图标。

- 修订 3 使用本体的随机编号生成器，修复没有 `od` 的固件中计费查询无法启动、账号同步失败，并移除 mwan3 临时包命名对可选工具的依赖。
- LuCI 拆分六个页面，控制台以端口卡片展示链路、双栈、实际账号、收发流量与速率；设置页继续使用 LuCI 表单。
- App 自动发现局域网路由端，连接后融合控制台、计费汇总、路由账号、诊断、日志及常用设置；新增显式允许的私有地址 HTTP 连接。
- 路由账号停用只影响自动登录；设置和账号同步共用写入锁，保留其他上游分配及凭据。
- 宿舍网按当前端口源 IP 读取实际认证账号，适配外部脚本切换账号。

- 修订 2 移除可选 `cksum` 依赖，修复多上游锁冲突及出口路由编号失败，并清理旧规则。
- LuCI 每 2 秒显示检测步骤，检测时保留最近完成结果；计费页面自动查询各接口当前账号并按账号汇总。
- 计费优先使用 lgn2jfself 免密跳转，其他账号继续使用隔离的登录与验证码会话。
- 安装包分阶段构建，优先 APK，完成后才开始 IPK。

- 与 App 统一版本，新增经 HTTPS/rpcd 登录的状态、指定上游认证和选定账号同步。
- 支持多上游独立账号、冷却、状态，IPv4/IPv6 分别选择逻辑接口、设备和源地址。
- 外网探测与门户会话分开判断，保留有效认证，增加固定地址的 HTTPS 补充目标。
- 修复未认证 lgn 被依赖账号信息的探测遗漏；支持手动补交双栈认证。
- 同一物理出口互斥，明确账号拒绝才轮换，已在线或未知响应不轮换。
- “账号已在线”需重新核对当前出口；登录后的会话与互联网结果分别显示，避免其他上游的登录状态造成误报。
- 增加源地址、设备绑定的内存出口路由，适配没有主默认路由的上游；自动维护并清理专用 mwan3 规则。
- 新增 LuCI 计费查询与验证码，概览先显示，按管理员、上游、账号与出口隔离、复用会话。
- 同步账号使用隔离暂存、密码回读与原子替换，保留其他设置。
- 版本号从路由端独立编号 0.3.0 改为与 App 同步的 0.1.6；旧 IPK 安装时可能需要 `--force-downgrade`。

## 0.3.0

- 修复 lgn6 被固定为 IPv4 地址，改用校园 IPv6 网关。
- IPv6 发现失败时允许已验证门户的 IPv4 认证。
- 认证提交结果不明确时停止，不向备用网关重复提交。
- 默认请求超时设为 3 秒，不再额外延长最大请求时间。
- 修复 macOS 离线验证中 wc 字节数空格导致的误判。
- 重试冷却从探测结束计算，避免慢网络消耗退避时间后立刻重复请求。
- 增加自动上游合并、协议变更审查及冲突保留流程。
- 增加 9 类平台的 IPK/APK SDK 编译、Actions 附件与版本标签发布；本体和 LuCI 包统一版本并记录校验和。
- 修复 SDK 构建中工作目录未创建的问题，并增加包准备与编译配方的回归检查。

# OpenWrt 端变更记录

## 0.2.0 - 2026-08-30

- 新增轻量 `procd` 常驻服务和 `ifup` 事件触发。
- 迁移 `bjut-sushe`、`bjut_wifi`、`lgn` 登录协议。
- 所有请求绑定指定上游设备，校园网域名固定到已知网关地址。
- 新增校园网 IPv4、传输类型、SSID/BSSID 和只读门户联合校验。
- bjut-sushe 优先正常 TLS 验证，并为原项目记录的旧证书提供 SPKI 固定回退。
- 旧式 HTTP 无线模式始终强制精确匹配配置的 BSSID，即使一般严格校验已关闭也不可绕过。
- lgn 保留 UTF-16 XOR 字段编码以及 IPv6 发现前置条件。
- 新增多账号顺序轮换、离线二次确认、指数退避和账号拒绝冷却。
- 凭据请求 URL 改由 curl 配置标准输入提供，避免账号密码出现在进程参数。
- 新增只写 `/var/run` 的脱敏 JSON 状态和可选 LuCI JavaScript 页面。
- 新增模拟网关集成测试、随机 Unicode 编码对照测试和静态结构检查。
