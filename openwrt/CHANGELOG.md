# 变更记录

## 0.1.6 - 2026-10-11

- 与 App 统一版本，新增经 HTTPS/rpcd 登录的状态、指定上游认证和选定账号同步。
- 支持多上游独立账号、冷却、状态，IPv4/IPv6 分别选择逻辑接口、设备和源地址。
- 外网探测与门户会话分开判断，保留有效认证，增加固定地址的 HTTPS 补充目标。
- 修复未认证 lgn 被依赖账号信息的探测遗漏；支持手动补交双栈认证。
- 同一物理出口互斥，明确账号拒绝才轮换，已在线或未知响应不轮换。
- 增加源地址、设备绑定的内存出口路由，适配没有主默认路由的上游；自动维护并清理专用 mwan3 规则。
- 新增 LuCI 计费查询与验证码，概览先显示，按管理员、上游、账号与出口隔离、复用会话。
- 同步账号使用隔离暂存、密码回读与原子替换，保留其他设置。
- 版本号从路由端独立编号 0.3.0 改为与 App 同步的 0.1.6；旧 IPK 安装时可能需要 `--force-downgrade`。

## 0.3.0

- 修复 lgn6 被固定为 IPv4 地址，改用校园 IPv6 网关。
- IPv6 发现失败时允许已验证门户的 IPv4 认证。
- 认证提交结果不明确时停止，不向备用网关重复提交。
- 默认请求超时设为 3 秒，不再额外延长最大请求时间。
- 修复 macOS 离线验证中 wc 字节数空格导致的误判。
- 重试冷却从探测结束计算，避免慢网络消耗退避时间后立刻重复请求。
- 增加自动上游合并、协议变更审查及冲突保留流程。
- 增加 9 类平台的 IPK/APK SDK 编译、Actions 附件与版本标签发布；本体和 LuCI 包统一版本并记录校验和。
- 修复 SDK 构建中工作目录未创建的问题，并增加包准备与编译配方的回归检查。

# OpenWrt 端变更记录

## 0.2.0 - 2026-08-30

- 新增轻量 `procd` 常驻服务和 `ifup` 事件触发。
- 迁移 Type 1 `bjut-sushe`、Type 2 `bjut_wifi`、Type 3 `lgn` 登录协议。
- 所有请求绑定指定上游设备，校园网域名固定到已知网关地址。
- 新增校园网 IPv4、传输类型、SSID/BSSID 和只读门户联合校验。
- Type 1 优先正常 TLS 验证，并为原项目记录的旧证书提供 SPKI 固定回退。
- 旧式 HTTP 无线模式始终强制精确匹配配置的 BSSID，即使一般严格校验已关闭也不可绕过。
- Type 3 保留 UTF-16 XOR 字段编码以及 IPv6 发现前置条件。
- 新增多账号顺序轮换、离线二次确认、指数退避和账号拒绝冷却。
- 凭据请求 URL 改由 curl 配置标准输入提供，避免账号密码出现在进程参数。
- 新增只写 `/var/run` 的脱敏 JSON 状态和可选 LuCI JavaScript 页面。
- 新增模拟网关集成测试、随机 Unicode 编码对照测试和静态结构检查。
